TRELLIS

Obsidian

简洁

3D 资产生成。根基是一个统一结构潜向量(unified Structured LATent)表示，能够解码到不同的输出格式。通过把稀疏 3D 网格和多角度 feature 结合起来，综合地掌握了结构和纹理信息。

SLAT 表示

对于 3D 资产 O ，我们这样编码它的集合和表面信息：

z={(zi,pi)}i=1L,zi∈RC,pi∈{0,1,…N−1}3

这是定义在一个 3D 网格的局部潜向量集合上的。
这里的 pi 是和 O 的表面相交的体素的位置， zi 是局部潜向量。 N 是空间长度， L 是所有的体素。直觉上， pi 描述了 3D 资产的外形， zi 描述了细节。
因为 3D 数据的稀疏性，这里的 L≪N3 。

SLAT编解码

作者提出了一个有效的编码方案，并且介绍了多种解码器方便不同格式输出。

Visual feature aggregation

首先把3D 资产 O 变成一个体素化 feature f={(fi,pi)i=1L} 。这里 pi 是活跃的体素，和上式定义的一样。 fi 是一个visual feature记录了局部细节结构和表面信息。
怎么获得 fi 呢？作者提出可以聚集从 O 密的多视角图片提取 feature。从一个球上随机选取一个相机视角并渲染成图片，然后使用预训练 DINOv2编码器提取 feature map。每个体素都被投影到feature map 上来获得对应位置的 feature，然后取个均值就得到了 fi 。

Sparse VAE for structured latents

有了 f ，作者使用基于 transformer的VAE架构来编码。
特别地，对于一个编码器 E 首先把 f 编码成 z ，然后用解码器 D 把 z 变成某种 3D 表示。然后用ground truth进行端到端的训练。和 VAE 的传统一样，还有一个 KL 项来鼓励 z 靠近正态分布。

为了处理稀疏体素，我们序列化输入 feature 然后加上位置编码，产生了可变上下文长度 L，被送入 transformer。其中还有 swin transformerblock，提升了性能。

Decoding

这个潜变量可以被解码成很多种 3D 表示。作者举了三个例子 3D 高斯，Radience Field，mesh。

3D 高斯

DGS:{(zi,pi)}i=1L→{{(oik,cik,sik,αik,rik)}k=1K}i=1L
  • 位置 o
  • 颜色 c
  • 缩放 s
  • 不透明度 α
  • 旋转 r

最后 loss 三部分： L1,LD−SSIM,LLPIPS

Radience Fields

DRF:{(zi,pi)}i=1L→{(vix,viy,viz,vic)}i=1L

Meshes

DM:{(zi,pi)}i=1L→{{(wij,dij)}j=164}i=1L

这里 wij∈R45 是 Flexicubes 的参数，然后 dij 是体素八个顶点的signed distance value。
最后算 depth 和 normal 的 L1loss 即可。

SLAT生成

讲完了表示，下面进入生成。

Rectified flow models

使用一个线性插值： x(t)=(1−t)x0+tϵ ，表示条件概率路径。然后可以获得 VF v(x,t)=∇tx ，能够让噪音采样向数据分布移动，可以用一个条件流匹配目标

LCFM(θ)=Et,x0,ϵ‖vθ(x,t)−(ϵ−x0)‖22

Sparse Structure Construction

在第一阶段，目标是产生稀疏的结构 {pi}i=1L 。为了用神经网络生成，作者把稀疏的活跃体素变成一个密集的二元 3D 网格 O∈{0,1}N×N×N ,1表示活跃。
直接生成这样的密集网格是很昂贵的。作者引入了一个简单的带有三维卷积的 VAE来把它压缩到一个低分辨率 feature 网格 S∈RD×D×D×CS 。这也把离散的值变成连续的 feature，方便rectified flow训练。
作者使用图 3b中的 transformer 作为 backbone GS 。密集的噪音网格被序列化，带有位置编码，然后被送入到 transformer 来去噪。时间步信息使用 adaLN 和门控机制来整合。条件使用 crossattention 来插入。文字用 CLIP，图片用 DINOv2来获得它们的 feature。最后去噪的网格 S 被解码成离散的网格 O ，然后被转换成体素 pi 作为稀疏的结构。
