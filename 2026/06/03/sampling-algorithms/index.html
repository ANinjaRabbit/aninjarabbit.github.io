Metropolis-Hasting Algorithm

在第 τ 步，状态为 z(τ) , 我们可以从 qk(z|z(τ)) 中采样然后以如下概率接受：

Ak(z∗,z(τ))=min(1,p~(z∗)qk(zτ|z∗)p~(z(τ))qk(z∗|z(τ)))

这个不需要 p~ 是归一化的。
我们可以证明 p(z) 是invariant distribution, 因为满足detailed balence:

p(z)qk(z′|z)Ak(z′,z)=p(z′)qk(z|z′)Ak(z,z′)

其中 q 尝试选用正态分布 q(x′|x)∼N(x,σ2) 。但是对于方差 σ 来说，如果太大了，那么采样很有可能落在一些 p(z) 很小的地方，那么拒绝率会很高。但是，如果说太小了，那么每一步走的很小，需要更长时间converge，即使接受率很高。对于高维分布，如果说各个方向尺度差异很大的话，这个算法需要很久才能收敛。

Gibbs sampling

这可以被视为上面方法的一个特例。考虑 p(z1,…,zm) ，我们首先指定初始值，然后每一步替换其中一个变量基于： p(zi|z∖i)

首先我们发现 p(z) 是一个invariant distribution。满足ergodic的一个充分条件是这个条件概率处处不为 0。否则有些点可能无法达到。注意到令 qk(z∗|z)=q(zk∗|z∖k) 可以得到这是Metropolis-Hasting Algorithm 的一个特殊情况：

Langevin Sampling

Energy based models

生成式模型： p(x|w) ，其中 w 是可学习参数，然后 x 是data.为了让这个概率分布成立，必须满足

∫p(x|w)dx=1

如果我们不考虑这个归一化的话，我们可以考虑一类energy-based models.
加入我们有函数 E(x,w) 。考虑 exp⁡{−E(x,w)} 是一个非负量，可以认为是一个没有归一化的概率分布。因此

p(x|w)=1Z(w)exp⁡{−E(x,w)}

其中归一化函数 Z(w) 被称为partition function

Z(w)=∫exp⁡{−E(x,w)}dx

注意到这个 Z 是w-dependent, 会造成一些问题。比如

ln⁡p(D|w)=−∑n=1NE(xn,w)−Nln⁡Z(w)

其中 D=(x1,…xn) 是数据。这时，后面的这一项很难求导。然而可以把概率模型看作energy-based model.

Maximizing the likelihood

∇wln⁡p(x|w)=−∇wE(x,w)−∇wln⁡Z(w) Ex∼pD[∇wln⁡p(x|w)]=−Ex∼pD[∇wE(x,w)]−∇wln⁡Z(w)

而我们有

Z(w)=∫exp⁡{−E(x,w)}dx−∇wln⁡Z(w)=∫{∇wE(x,w)}p(x|w)dx=Ex∼M[∇wE(x,w)] Ex∼pD[∇wln⁡p(x|w)]=−Ex∼pD[∇wE(x,w)]+Ex∼M[∇wE(x,w)]

Langevin dynamics

Ex∼pD[∇wE(x,w)]≈1N∑n=1N∇wE(xn,w)

the second term can be sampled using Markov chain Monte Carlo.One popular approach is called stochasti gradient Langevin dynamics or Langevin sampling.

s(s,w)=∇xln⁡p(x|w)=−∇xE(x,w)

drawing a x(0) from a prior distribution:

x(τ+1)=x(τ)+η∇xln⁡p(x(τ),w)+2ηϵ(τ),τ∈1,…,T

It can be show that η→0 and T→∞ , x(τ) is an independent sample from p(x) , We can repeat that to get {x1,…,xM}
and then we have

Ex∼pM(x)[∇wE(x,w)]≈1M∑m=1M∇wE(xm,w)

but this is consuming, then we can use contrastive divergence. It start from a training data point xn .Hinton proposes to only go a few steps (even only one step).
