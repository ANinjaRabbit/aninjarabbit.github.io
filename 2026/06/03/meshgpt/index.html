MeshGPT

Obsidian

简介

采用自回归来直接生成 mesh。首先训练一组编解码器，让三角形能够被编解码，这样就获得一个词汇表。然后自回归预测词汇表即可。

Learning Quantized Triangle Embeddings

要想用 transformer 自回归生成 mesh，我们首先要定义生成的顺序。作者使用和 Polygen 相同的方案：每个面的顺序基于最小的端点序号，端点被按照 (z−y−x) 来排序。
首先考虑一种表示 Mesh 的方式：一个三角形序列

M:=(f1,f2,…,fN)

一共有 N 个面， fi∈Rnin 有 nin feature。一个简单的方法是三个端点，每个端点三个坐标，序列长度就是 9N
然而这种方法有两个挑战：首先这样的序列长度太长了。其次，这样表示离散的位置不能有效的捕捉几何。为了解决这两个挑战，作者使用一个 encoder-decoder架构来学习几何 embeddings，使用残差向量量化。
网络的 encoder E 使用图卷积，这里每一个面形成一个 node，相邻的面用无向边连接起来。输入的面节点 feature 由端点的九个位置编码，面法向量，夹角和面积组成。这些 feature 经过 堆叠的SAGEConv 层的处理，提取出每个面的 feature。

Z=(z1,z2,…,zN)=E(M)

然后使用residual vector quantization(RQ)。作者发现使用一个 code 来描述一个面不太够。相反，作者使用了 D 个 code 来描述。然后，相比于直接使用 D 个 code，采用下述方式效果更佳： 先将特征通道分配到各个顶点，通过共享顶点索引聚合特征，再对这些基于顶点的特征做向量量化； 最终每个顶点得到 (D/3) 个量化码，等效折算下来每个面仍等价拥有 D 个量化码。
形式化：

T=(t1,t2,…,tN)=RQ(Z;C,D)ti=(ti1,…,tiD)

这里每一个 token tid 是一个序号，指向 codebook C 中的 embedding e(tid)
解码器把量化后的 face embedding 变成三角形。首先，D个堆叠的 feature 被 reduce 到一个feature：

Z^=(z^1,…,z^N),zi^=⊕v=02∑d=1D/3e(ti3v+d)

这里的 ⊕ 表示concatenation。
得到的 face embedding 被拍成之前描述的顺序，然后一个 1D ResNet34 解码头 G 把得到的序列变成重建的 mesh

M^=G(Z^)

这里一个面由九个坐标来表示。作者发现把这些坐标看成离散的变量来预测，会带来更加准确的重建。
在训练完了之后，图编码器 E 和 codebook C 被整合到了 transformer 训练中。

Mesh Generation with Transformers


主要结构就是一个 decoder only transformer 架构。
输入一个 Mesh，通过图卷积 Encoder 和 RQ 量化，最后得到的 embedding 被加上开头和结尾标志输入 transformer。训练最大化目标：

∏i=1N∏d=1Dp(tid|e(t<id),e(ti<d);θ)

然后训练完了之后，就可以从开始标志开始自回归生成序列了。因为这样产生的 mesh 是 triangle soup 形式，最后会使用一个简单的操作来合并靠近的端点。
