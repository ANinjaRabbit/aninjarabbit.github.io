简介

像 NeRF 一样的网络很难训练。作者使用多功能input encoding 和一个多分辨率 hashtable 来对这一过程进行了加速。

Multiresolution Hash Encoding

给定一个 FCN m(y;Φ) ，我们关心它的输入的一个编码 y=enc(x;θ) ，这个编码能够显著提升性能且没有带来一些显著的经常性开销。最常见的就是 nerf 中用的正余弦函数。这里我们想推广它。
这样的网络有两部分参数 Φ,θ 。 θ 被排成 L 个水平，每一个有至多 T 个 feature 向量，它们的维度是 F 。我们指定一个最小和最大分辨率： [Nmin,Nmax] ，然后获得 L 个中间的分辨率

Nl:=⌊Nmin⋅bl⌋b:=exp⁡(ln⁡Nmax−ln⁡NminL−1)

我们考虑其中一个水平 l 。然后输入的坐标 x∈Rd 被缩放：

⌊xl⌋:=⌊x⋅Nl⌋,⌈xl⌉=…

那么这里的 ⌊xl⌋,⌈xl⌉ 张成了一个体素（就像正方体的斜对角），这个体素有 2d 个整数顶点。我们把每一个顶点 map 到这个水平的 featurevector 数组里面的某一个条目，这个数组有最多 T 的固定的大小。对于比较粗糙的水平，这里的 (Nl+1)d≤T ，那么就是一个 1:1 对应。否则，我们使用 h:Zd→ZT 来获得序号，像一个哈希表，但是不处理碰撞。我们用梯度优化来存储合适的 feature vector。那么这里的参数 θ 就是 T⋅L⋅F=O(T) 。我们使用空间哈希函数

h(x)=(⊕i=1dxiπi)modT

这里的 ⊕ 是异或， πi 是大质数。
最后得到的 feature vectors 被 lerp 成输入点的 feature，然后和辅助输入 ξ∈RE 被拼成 y∈RLF+E 然后放到MLP 里面。
