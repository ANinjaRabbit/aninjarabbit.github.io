2026.06.03 Notes

score matching

Obsidian

Def:

s(x)=∇xln⁡p(x)

注意这里的梯度是对 data 向量的梯度。所以我们想获得数据的真实分布，就可以想办法用另一个函数去逼近这个 score 函数，然后做积分就可以得到。

score loss function

J(w)=12∫‖s(x,w)−∇xln⁡p(x)‖2p(x)dx

有两种方式来用神经网络表达 s(x,w) 。第一种就是直接逼近，第二种就是用一个标量函数然后通过求导。但是这需要多次求导，复杂度过大。所以使用第一种。

Modified score loss

这个 loss function 不能直接用，因为不知道真实的 p(x) 。我们有 D=(x1,…,xN) 优先的数据，我们可以获得一个经验分布：

pD(x)=1N∑n=1Nδ(x−xn)

这里的 δ 为迪拉克 δ 函数：

δ(x)=0,x≠0∫δ(x)dx=1.

然而这个函数并不可导。所以我们可以把它给抹平一点：(做一个卷积)

qσ(z)=∫q(z|x,σ)p(x)dx

这里的 q(z|x,σ) 是一个 noise kernel。通常选择高斯：

q(z|x,σ)=N(z|x,σ2I)

然后我们可以把 qσ(z) 作为对 data 分布的近似：

J(w)=12∫‖s(z,w)−∇zln⁡qσ(z)‖2qσ(z)dz

展开：

J(w)=12∫‖s(z,w)‖2qσ(z)dz−∫s(z,w)T∇zln⁡qσ(z)qσ(z)dz+12∫‖∇zln⁡qσ(z)‖2qσ(z)dz

注意到

∇zln⁡qσ(z)=1qσ(z)∇zqσ(z)

那么可以写成

J(w)=12∫‖s(z,w)‖2qσ(z)dz−∫s(z,w)T∇zqσ(z)dz+12∫‖∇zln⁡qσ(z)‖2qσ(z)dz

第一项：

12∫‖s(z,w)‖2qσ(z)dz=12∬‖s(z,w)‖2q(z|x,σ)p(x)dxdz

第二项：

=−∬s(z,w)T∇zq(z|x,σ)p(x)dxdz=−∬s(z,w)T∇zln⁡q(z|x,σ)q(z|x,σ)p(x)dxdz

第三项与 w 无关。
那么变成

J(w)=12∬‖s(z,w)‖2q(z|x,σ)p(x)dxdz−∬s(z,w)T∇zln⁡q(z|x,σ)q(z|σ,x)p(x)dxdz+C=12∬‖s(z,w)−∇zln⁡q(z|x,σ)‖2q(z|x,σ)p(x)dxdz+C

然后使用经验密度：

J(w)=12N∑n=1N∫‖s(z,w)−∇zln⁡q(z|x,σ)‖2q(z|xn,σ)dz+C

然后使用高斯

q(z|x,σ)=N(x,σ2I)

这里推导单变量：

ln⁡q(z|x,σ)=ln⁡12πσ2exp⁡{−(x−z)22σ2}=−(x−z)22σ2−12ln⁡2π−ln⁡σ∇zln⁡q(z|x,σ)=x−zσ2=−1σϵ

考虑diffusion中的

z∼N(αtx,(1−αt)I)

注意这里的 αt 和 diffusion 中的 α¯t 是一个意思。那么这里就有

∇zln⁡q(z|x,σ)=−11−αtϵ

因此前面的score loss 事实上是衡量网络预测和噪音 ϵ 之间的差距。那么这个过程就和 denoise 过程对应起来了。然后只要通过Langevin sampling 就可以得到采样点了。

Noise Variance

这个方法存在一些问题。比如这里的 s 可能在某些缺少样本不准确，导致 Langevin sampling 不准确。这些问题可以这样解决：选择一个足够大的 σ2 。然而这样会导致空间扭曲，不准确。所以需要一个 trade-off。我们考虑一个方差序列：

σ12<⋯<σT2

那么这个 score network 变成将方差视为输入的网络： s(x,w,σ2) 。对每个样本点：

12∑i=1Lλ(i)∫‖s(z,w,σi2)−∇zln⁡q(z|xn,σi)‖2q(z|xn,σi)dz

这里的 λ(i) 是权重。 i=L,L−1,…,2,1 。这个方法称为annealed Langevin dynamics。

Stochastic differential equations

dz=f(z,t)dt+g(t)dv

这里的 dv 代表 diffusion。它对应的相反形式：

dz={f(z,t)−g2(t)∇zln⁡p(z)}dt+g(t)dv

那么forward SDE 就可以视为加噪音的过程，而只需要通过求解 reverse SDE 就可以获得图像。那么我们就需要一个神经网络去预测这里的 score function，和前面的想法不谋而合。最后用Eular-Maruyama求解即可。
