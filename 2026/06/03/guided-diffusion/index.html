Guided Diffusion

Obsidian

我们生成的图像可能需要有条件： c 。最简单的方式是把 c 视为输入： g(z,w,t,c) ，然后使用 {xn,cn} 去训练。主要的限制是网络可能给条件很小的权重，甚至直接忽略条件。所以我们需要一种平衡多样性和条件的方法。这就是guidance的作用，主要有两种方式。

Classifier Guidance

假设有一个分类器 p(c|x) ，从 score function的角度考虑扩散模型：

∇xln⁡p(x|c)=∇xln⁡{p(c|x)p(x)p(c)}=∇xln⁡p(x)+∇xln⁡p(c|x)

其中第一项是无条件的概率，第二项表示把denoising process往分类器中条件的概率大的方向推。那么我们可以引入一个超参 λ :

score(x,c,λ)=∇xln⁡p(x)+λ∇xln⁡p(c|x)

一个问题是这种方法必须要训练一个分类器。而且这种分类器必须能够在有噪音的情况下分类。

Classifier-free guidance

如果我们对上面的score做一点变换：

score(x,c,λ)=λ∇xln⁡p(x|c)+(1−λ)∇xln⁡p(x)

这是一个凸组合。对于 λ>1 表示要让模型减小 diversity 来增强 condition。
而且，我们可以把这两个概率用同一个神经网络来表示，而对于无条件的概率，则可以把 c 设置成一个null 值，比如 0 ，以某个概率。
