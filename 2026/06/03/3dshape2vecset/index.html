3DShape2VecSet

Obsidian

简介

经典作品。提供了一种3D 图形编码和解码成神经场的方案。

Radial Basis Functions

一组基函数 ϕ(x,xi) ，可以用来表示一个函数

O^RBF(x)=∑i=1Mλi⋅ϕ(x,xi)

这里的 ϕ(x,xi) 是一个基函数，一般这样定义（相当于衡量相似性或者不相似性）

ϕ(x,xi)=ϕ(‖x−xi‖)

之所以叫 radial，因为它只与距离有关。其实作用相当于对离散点的特征进行加权平均

Latent Representation for Neural Fields

我们希望找到一组编解码器，能输出neural fields:

O^NN(x)=NN(x,f)

这里 x∈R3 ， f∈RC 表示latent feature。但是这种方法只用了一个 global 的 f ，这个 f 与位置没有关系。所以以往的文章引入coordinate-dependent feature fx ，可以这样定义

fx=F^KN(x)=∑i=1Mfi⋅1Zϕ(x,xi)

这里的 Z 代表 normalization，就是所有 RBF 值的和。那么这里的representation 就可以定义为

{fi∈RC,xi∈R3}i=1M

然后一个 MLP : RC→[0,1] 就可以用来把这个 fx 变成 occupancy

O^3DILG(x)=MLP(F^KN(x))

Neural networks with latent sets

作者接着上面的方法提出了

F^(x)=∑i=1Mv(fi)⋅1Zeq(x)Tk(fi)/d

注意这里并没有显示编码 xi ，而是将其放在 fi 中隐式表达。然后只用一个单层 FC 获得最终的 occupancy

O^(x)=FC(F^(x))

本篇文章的最大特色就在于这里的表示其实只是一个 latent 的集合

{fi∈RC}i=1M

Network Architecture

主要的架构是 VAE。

Shape encoding

首先在一个图形表面采样点集 {xi∈R3}i=1N⟹X∈R3×N 。这适用于各种表达。
首先的挑战就是要把点云变成一个小的latent vector集合。
之前作品的想法是分成一些 patch 然后每个 patch 学习一个 feature。作者探索了一种更加成功的方法，这和 transformer 架构有很好的兼容性。考虑两个选项。
首先是去定义一个可学习的 query。使用crossattention

Enclearnable(X)=CrossAttn(L,PosEmb(X))∈RC×M

这里的 L∈RC×M 是一个可学习的query集，每个条目是 C 维的， PosEmb:R3→RC
另一种方法是利用点云本身。我们首先做一个降采样 X0=FPS(X)∈R3×M

Encpoints(X)=CrossAttn(PosEmb(X0),PosEmb(X))

可以看作是一种“自注意力”。M 的选择需要一个 trade-off。

KL regularization block

首先把 latents 线性投影到mean 和 variance，通过两个网络分支

FCμ(fi)=(μi,j)j∈[1,2,…,C0]FCσ(fi)=(log⁡σi,j2)j∈[1,2,…,C0]

这里 FC 都是 RC→RC0 。这里的 C0≪C 。这样对于 diffusion model 就可以在很小的 latent 上面训练了！（LDM） ∀i∈[1,2,…M],j∈[1,2,…C0]

zi,j=μi,j+σi,j⋅ϵ

然后 KL regularization 写成

Lreg({fi}i=1M)=1MC0∑i=1M∑j=1C012(μi,j2+σi,j2−log⁡σi,j2)

shape decoding

作者使用 self attention block

{fi}i=1M←SelfAttn(l)({fi}i=1M),l=1,…,L

这里的 l 表示层数。最后，用上面的 F^ 和 O^ 来获得 occupancy。

这里的 Lrecon 定义如下

Lrecon({fi}i=1M,O)=Ex∈R3[BCE(O^(x),O(x))]

就是一个binary cross entropy loss，和二分类一样。

Shape Generation

这里使用 LDM 的思想，在 latent space 里面训练 diffusion。去噪目标：

Eni∼N(0,σ2I)1M∑i=1M‖Denoiser({zi+ni}i=1M,σ,C)−zi‖22
