TRELLIS

DINOv2 提特征，然后通过cross-attention 注入 KV. 总体上流程是每一个 block 内做一次 self-attention 再做一次cross-attention。

Stochastic

multidiffusion

每个 step 对每一个图片独立预测 velocity，然后取平均。

TRELLIS 2

DINOv3-L 提特征，依然是 cross-attention注入 KV。流程和 1 一致。

Direct3D

分别通过 CLIP 和 DINOv2 获得semantic-level information 和 pixel-level information。语义信息分两条路：首先获得的 cs 使用 cross-attention融合，然后classification token被和 time embedding 融合然后用adaLN-zero注入。像素信息则是先和 token concat在一起，然后最后再丢弃这些维度。

Direct3D-S2

文章中特别提到，一般的模型都是用dinov2去提取特征然后直接做cross attention。然而对于绝大多数输入图像而言，超过一半的区域均为背景区域；这不仅会带来额外的计算开销，还可能破坏生成网格与条件图像之间的特征对齐效果。为缓解该问题，本文提出一种稀疏条件机制：从输入图像中有选择地提取并处理前景稀疏特征 Token，仅用于后续交叉注意力计算。形式化地，给定输入图像 I ，稀疏条件 Token c 的计算方式如下：

(9)c=Linear(f(EDINO(I)))+PE(f(EDINO(I)))

其中：

  • EDINO 代表 DINO-v2 编码器；
  • f(⋅) 表示依据掩码提取前景 Token的操作；
  • PE(⋅) 为绝对位置编码；
  • Linear(⋅) 表示线性映射层。
    之后利用最终得到的稀疏条件 Token c 与噪声 Token 进行交叉注意力计算。
